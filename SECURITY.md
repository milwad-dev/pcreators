# Security Policy

## Supported Versions

The latest release of `pcreators` receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, email the maintainer directly at **milwad.dev@gmail.com** with the
details. You will receive a response as soon as possible, and the issue will be
addressed promptly.

Please include, where possible:

- A description of the vulnerability and its impact.
- Steps to reproduce it.
- Any suggested fix.

Thank you for helping keep pcreators and its users safe.
